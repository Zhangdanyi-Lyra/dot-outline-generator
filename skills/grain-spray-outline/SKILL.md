# 颗粒喷绘轮廓

把用户图像中的主体转成这套已确认的轮廓效果。先分清“新主体转换”“成品换色”“仅修外边”，避免把局部修改变成整图重绘。

## 视觉基准

资源路径均相对于本技能目录。生成新主体或判断风格时，先查看相应参考图：

- [黑灰基准](references/approved-gray.png)：用户确认的手绘外边、内侧喷绘宽度和纹理。可用[棋盘格预览](references/approved-gray-preview.png)观察透明过渡。
- [彩色基准](references/approved-blue.png)：用户最终恢复的蓝色第一版。可用[棋盘格预览](references/approved-blue-preview.png)检查其浅色过渡。
- [彩色基准的灰阶原件](references/color-source-gray.png)：用于复现、验证换色；不是所有任务的主体模板。

只迁移这些图的渲染效果。用户新上传的图决定主体、比例、动作、连接关系和孔洞，不复制参考图里的角色。

## 必须保留的视觉结构

- 主体内部及外部都透明，只保留轮廓、必要结构线和局部识别细节；原图的大片实色面也转为镂空。
- 灰黑版从外侧到内侧是：透明背景 → 轻微手绘黑色外边 → 暗灰 → 较浅、带颗粒的灰色喷绘 → 透明内部。
- 喷绘靠内的一侧直接消散，不能再出现一圈黑线、细灰线、白线、平行描边或内倒角。原物体必要的结构线不属于这种错误的“第二圈细边”。
- 内侧喷绘有一定宽度，覆盖不均、细颗粒随机，呈手工喷绘和扫描印刷质感。保留大块空白，避免细硬灰条、织物纹、粗糙污块和对称圆管高光。
- 最外边有克制的起伏、笔压和毛边；保留造型，不做夸张抖动。不要自动添加编号、文字或配饰。

## 按任务选择方法

### 新主体

读取 [references/generation.md](references/generation.md)，以用户原图为造型参考、黑灰基准为风格参考，用内置 `image_gen` 生成真正透明的灰阶 PNG。查看本地输入后再交给生成工具；不要以写着棋盘格的预览图作为编辑原件。

保留灰阶母版，再按用户选择进行确定性换色。这样以后换色可以复用同一套颗粒和形状。没有指定颜色时，续作沿用当前配色；首次转换默认黑灰。要求随机时从下面五色中选一个；要求“其他颜色”时排除当前主色。

### 成品换色

用户已选择局部像素编辑来保护确认过的效果。换色运行 [scripts/render_outline.py](scripts/render_outline.py)，不要为换色重新生成图形。

外轮廓和内部一起换成同一主色的浓淡：黑色对应主色，灰色对应主色逐渐混入白色，透明度原样保留。彩色版不保留黑色外圈。

| 名称 / 脚本参数 | 主色 |
| --- | --- |
| 蓝色 `blue` | `#4597F8` |
| 橙色 `orange` | `#FF5D00` |
| 黄绿色 `lime` | `#D4FF3A` |
| 粉色 `pink` | `#FF8BE8` |
| 赭棕色 `ochre` | `#966400` |

设原灰阶亮度为 `L`（0–255），主色为 `C`，输出颜色为 `C + (255 - C) × L / 255`。原 alpha、全透明像素和画布尺寸保持不变；颗粒的空间分布保留。

用户试过“最多只混入 22% 白色、提高饱和度”的方案后明确退回第一版。因此，**保留原有的浅色过渡，不自动压低提亮幅度**。如果用户再次评价内部发白，先解释当前映射；只有明确要求调整时再建立新版本，不擅自替换基准。

从灰阶母版执行，不要对上一次彩色成品反复套色。如果只有彩色成品，先找对应母版；找不到时说明不能保证完全复现原纹理浓淡，不把彩色图直接当灰阶母版。

```bash
python3 "<技能目录>/scripts/render_outline.py" recolor \
  --source "<灰阶母版.png>" --color blue \
  --output "<输出目录>/object-blue.png" \
  --preview "<输出目录>/object-blue-preview.png"
```

随机换色使用 `--color random`；可附加 `--exclude blue` 排除当前色。明确指定的其他颜色可使用引号包裹的十六进制色值。脚本依赖 Pillow、NumPy，输出文件不得与原件重名。

### 仅增加外边手绘感

读取 [references/local-edits.md](references/local-edits.md)。只修改最外侧深色边及相邻的抗锯齿像素，锁定内部喷绘、识别细节和封闭透明区。先检查编辑区域，再执行像素编辑；修改后验证保护区逐像素不变。彩色成品优先回到对应灰阶母版修外边，再按原主色换色。

## 验收与交付

检查完整造型、内侧无第二圈细线、宽而柔软的颗粒喷绘、轻微手绘外边、真正透明的内部及背景。彩色版需确认外轮廓也已换色。

透明图在某些查看器中可能显示异常的白色斑块；不要据此直接改动 alpha。先用脚本在棋盘格上做实际合成，必要时以深色背景复核：

```bash
python3 "<技能目录>/scripts/render_outline.py" preview \
  --source "<透明PNG>" --output "<预览.png>" --background checker
```

交付透明 PNG 和单独的预览图，明确棋盘格仅在预览中。保留灰阶母版用于后续换色。简要说明主色和下载位置；只有用户确认后才更新已确认的参考基准。
